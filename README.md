# 📊 Sales and Profit Analysis Dashboard

## 📌 Overview
This project is an interactive Power BI dashboard developed to analyze sales, profit, customer segments, shipping modes, and regional performance. The dashboard also includes a 15-day sales forecasting feature to predict future sales trends and support business decision-making.

---

# 🎯 Objectives
- Analyze overall sales and profit performance
- Identify top-performing categories and regions
- Track monthly sales and profit trends
- Analyze customer segments and payment methods
- Forecast future sales using historical data

---

# 🛠 Tools & Technologies Used
- Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Excel / CSV Dataset

---

# 📊 Dashboard Features

## KPI Metrics
- Total Sales
- Total Profit
- Total Quantity Sold
- Average Delivery Days

## Sales Analysis
- Sales by Category
- Sales by Sub-Category
- Sales by Segment
- Sales by Ship Mode
- State-wise Sales Analysis

## Profit Analysis
- Monthly Profit Trends
- Regional Profit Analysis
- Profit Forecasting

## Forecasting
- 15-Day Sales Forecasting
- Trend Prediction using historical data

---

# 📌 Key Insights
- Technology and Office Supplies generated the highest sales.
- Consumer segment contributed the maximum revenue.
- Standard Class shipping mode had the highest sales volume.
- Sales showed strong growth toward the year-end period.
- Western region performed better compared to other regions.
